# Silicon Nova Website

A modern, high-performance website for Silicon Nova - a premium freelancing company specializing in building custom websites for clients in Kenya and globally.

## 🚀 Features

- **Modern Design**: Sleek, tech-inspired aesthetic with dark blues, metallic grays, and neon accents
- **Fully Responsive**: Mobile-first design that works seamlessly across all devices
- **High Performance**: Optimized with code splitting, lazy loading, and image optimization
- **SEO Optimized**: Meta tags, structured data, and semantic HTML for better search rankings
- **Accessible**: WCAG 2.1 Level AA compliant with keyboard navigation and screen reader support
- **Interactive Components**: Smooth animations, carousels, modals, and transitions
- **WhatsApp Integration**: Floating chat widget for instant communication
- **Multi-page Application**: Home, Services, Portfolio, About, Contact, and Blog pages

## 🛠️ Tech Stack

- **Frontend**: React 19.1.1
- **Build Tool**: Vite 7.1.7
- **Routing**: React Router v6
- **Styling**: CSS Modules with CSS Variables
- **Icons**: React Icons
- **Animations**: Framer Motion
- **SEO**: React Helmet Async
- **Fonts**: Google Fonts (Poppins, Open Sans)

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

### Typography

- Consistent spacing scale from 4px to 96px
